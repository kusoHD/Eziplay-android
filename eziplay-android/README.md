# Eziplay Android

Veb-sayt (index.html) WebView ichida ochiladigan Android ilova.

- Har safar `main` branchga push qilinganda GitHub Actions APK quradi.
- Tayyor APK: repozitoriyda **Actions** → oxirgi "Build APK" ishi → **Artifacts** → `eziplay-debug-apk`.
- Muhim: `app/src/main/assets/index.html` ni o'zgartirganda, o'sha fayl ustidan yangi nusxa yozing.
